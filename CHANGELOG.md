# Changelog
## [Unreleased]
- Fixed: the JSON Schema keywords WordPress validates are kept: `pattern`, `minLength`, `maxLength`, `minimum`, `maximum`, `exclusiveMinimum`, `exclusiveMaximum`, `multipleOf`, `minItems`, `maxItems`, `uniqueItems`, `minProperties`, `maxProperties`, `default`, `additionalProperties`, `patternProperties`, `anyOf`, `oneOf` and `title`, with the annotations `examples` and `deprecated`. Only `type`, `format`, `description`, `enum`, `properties` and `items` were written. This changes the document generated by default: it has more in it, and nothing less.
- Fixed: `items` and `properties` are kept when `type` is a list such as `["object", "null"]`, and for a schema with no `type`, e.g. an alternative of `oneOf`, which was written as a string.
- Changed: `'readonly' => true` is written as `readOnly`; a draft 4 boolean `exclusiveMinimum` or `exclusiveMaximum` is written as the limit, as draft 2020-12 has it; the empty `default` of an object is `{}`; `'default' => null` is left out unless `null` is one of the types.
- Added: the required arguments of a route are the `required` of its request body, and a draft 4 `required` list on an object is kept.
- Added: `RouteData::forNamespace()` describes the routes of a namespace with the `examples` and `deprecated` of their arguments, which WordPress leaves out of `WP_REST_Server::get_data_for_routes()`. The REST route and the WP-CLI command use it.
- Changed: with `--extract-common-types`, a component is named by its schema's `title`, or else after where it is (`License.status`, `posts.id.POST-PUT-PATCH.status`). Components were named after the property key, with `_1`, `_2` appended when two different schemas had the same key. The document generated without `--extract-common-types` is unchanged.
- Added: a schema with a `title` is extracted whatever its type.
- Added: `--strict-component-names` (`strict_component_names` over REST): two different schemas with one `title` are an error which names both places.
- Changed: the PHP namespace is `BrianHenryIE\OpenAPIGenerator`.
- Added: PHPUnit tests which need no WordPress (`composer test`).
